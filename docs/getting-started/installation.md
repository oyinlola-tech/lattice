# Installation

## Prerequisites

- **Node.js** >= 24.0.0
- **npm** >= 11.0.0 (or **pnpm** >= 9.0.0)

## Install a Package

Install any Zudo package from npm:

```bash
npm install @zudo/core
npm install @zudo/http
npm install @zudo/events
```

## Install the CLI

```bash
npm install -g zudo-cli
```

## Verify Installation

```bash
npx zudo --version
```
