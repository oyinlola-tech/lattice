# Installation

## Prerequisites

- **Node.js** >= 24.0.0
- **npm** >= 11.0.0 (or **pnpm** >= 9.0.0)

## Install a Package

Install any Zudolib package from npm:

```bash
npm install @zudolib/core
npm install @zudolib/http
npm install @zudolib/events
```

## Install the CLI

```bash
npm install -g zudolib-cli
```

## Verify Installation

```bash
npx zudolib --version
```
