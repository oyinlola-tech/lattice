# Installation

## Prerequisites

- **Node.js** >= 24.0.0
- **npm** >= 11.0.0 (or **pnpm** >= 9.0.0)

## Install a Package

Install any Zudojs package from npm:

```bash
npm install @zudojs/core
npm install @zudojs/http
npm install @zudojs/events
```

## Install the CLI

```bash
npm install -g zudojs-cli
```

## Verify Installation

```bash
npx zudojs --version
```
