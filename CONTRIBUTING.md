# Contributing

Thank you for your interest in contributing to Zudolib.

Please see [docs/contributing/INDEX.md](docs/contributing/INDEX.md) for the full contributing guide, including:

- Prerequisites and setup
- Project structure and package conventions
- Development workflow
- Testing requirements
- TypeScript conventions
- Security guidelines
- CI/CD requirements

## Quick Start

```bash
git clone https://github.com/oyinlola-tech/zudo.git
cd zudolib
pnpm install
pnpm run typecheck
pnpm test
```

## Reporting Issues

- Bug reports: [.github/ISSUE_TEMPLATE/bug-report.yml](.github/ISSUE_TEMPLATE/bug-report.yml)
