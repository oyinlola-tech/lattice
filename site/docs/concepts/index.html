CORE CONCEPTS

Understand the fundamental building blocks of the Zudo framework.

Zudo is built on six core concepts that work together to provide a complete application framework. Each concept solves a specific problem and integrates with the others through well-defined interfaces.

Concepts

Configuration

Layered configuration system with multiple sources, resolvers, schema validation, and sensitive value handling.

Contexts

Execution context propagation using AsyncLocalStorage for request-scoped data across async call chains.

Dependency Injection

Token-based DI container for loosely coupled architecture with singleton, transient, and scoped resolutions.

Lifecycle

Why These Concepts Matter

Every framework makes tradeoffs. Zudo's tradeoffs are deliberate: explicit over implicit, composable over monolithic, typed over dynamic.

Testability

DI containers and module boundaries make it trivial to swap implementations and write focused unit tests.

Predictability

Lifecycle state machines and configuration resolution order eliminate surprise behavior in production.

Scalability

Modules compose naturally. Start small, add features as modules, and the framework scales with your team.

Observability

Context propagation means every request, log, and metric carries full trace context without manual plumbing.
