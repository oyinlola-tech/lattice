GETTING STARTED

Everything you need to install, configure, and launch your first Zudo application.

v0.1.0 TypeScript 7.x Node ≥ 24

On This Page

Prerequisites Installation Quick Start Next Steps

Prerequisites

Before installing Zudo, make sure you have the following tools installed:

Node.js

≥ 24.0.0

Download from nodejs.org. Verify with node --version.

TypeScript

≥ 7.0.0

Install globally with npm i -g typescript or use npx tsc.

TIP

You also need a package manager: npm (≥ 11), pnpm, or yarn.

Installation

Install the core Zudo packages to get started:

npm

# Install core packages npm install @zudolib/core @zudolib/config @zudolib/logger # Or install the full framework npm install zudo

pnpm

# Install core packages pnpm add @zudolib/core @zudolib/config @zudolib/logger # Or install the full framework pnpm add zudo

yarn

# Install core packages yarn add @zudolib/core @zudolib/config @zudolib/logger # Or install the full framework yarn add zudo

PACKAGES YOU'LL USE

  • • @zudolib/core — Application lifecycle and runtime orchestration
  • • @zudolib/config — Layered configuration with multiple sources
  • • @zudolib/logger — Structured logging with transports

Quick Start

Three steps to a running Zudo application:

STEP 1 Install Dependencies
# Create project directory mkdir my-zudo-app && cd my-zudo-app # Initialize package.json npm init -y # Install Zudo packages npm install @zudolib/core @zudolib/config @zudolib/logger @zudolib/errors npm install -D typescript @types/node
STEP 2 Create Configuration

Create zudo.config.ts at the project root:

import { defineConfig } from "@zudolib/config"; export default defineConfig({ app: { name: "my-zudo-app", version: "1.0.0", }, server: { port: 3000, host: "0.0.0.0", }, logging: { level: "info", }, });
STEP 3 Create Application Entry Point

Create src/index.ts:

import { createContainer } from "@zudolib/core"; import { createLogger } from "@zudolib/logger"; async function main() { const logger = createLogger({ level: "info" }); const container = createContainer(); logger.info("Zudo application starting..."); // Register services container.register("logger", () => logger); // Start the application logger.info("Application ready!"); // Graceful shutdown const shutdown = async () => { logger.info("Shutting down..."); await container.dispose(); process.exit(0); }; process.on("SIGINT", shutdown); process.on("SIGTERM", shutdown); } main().catch(console.error);
RUN Start the Application
# Compile and run npx tsc && node dist/index.js # Or use tsx for direct execution npx tsx src/index.ts

TIP

Use tsx during development for faster iteration without a compile step.
