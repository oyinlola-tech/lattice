## Architecture Guardrails
- This project uses **interface-first design**. Define the interface before the implementation.
- The DI container uses **token-based registration** with string, symbol, or class tokens. Never bypass the container.
- Configuration follows a **layered source pattern** with priority ordering. Never hardcode configuration values.
- Execution context propagation uses **AsyncLocalStorage**. Never pass context manually through deep call chains — use `ContextProvider`.
- Errors must extend `FrameworkError` and use codes from the `ErrorCode` const object.
- The `Adapter` interface defines the contract for all external integrations. Never implement external connections without extending `BaseConfigurationSource` or `Adapter`.
- Lifecycle management uses a **state machine** pattern. Never mutate lifecycle state directly — use the provided methods.
- Configuration redaction is automatic for sensitive paths. Never log configuration values without going through `ConfigurationRedactor`.
